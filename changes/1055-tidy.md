`yokoten tidy` lists what is old on this machine: merged or gone branches, worktrees and desks with no work left, and the logs of gone desks. Each row says why, and its size. It changes nothing. `tidy --local` saves each one (a git bundle, a patch of unsaved changes, and `index.json`), then moves it into a dated trash folder. If a save fails, nothing moves. A desk in use is never touched. `tidy --empty` deletes trash older than 7 days, after one question (#1055).
