Security

A gh post now passes the guard only in a form yokoten can read. A program hidden in a variable or a backtick (`G="gh issue"; $G comment …`) followed by any post word or text option, short options run together with a text option (`-dt`, `-dc`, `-dn`, `-dF`, `-cb`), `gist create`, `release create` with files (after `--` too), and `--recover` are refused, with the fix "post it with `yokoten bot`". `yokoten bot` refuses the same forms, with a fix for each, since it can't read their text. The bot also no longer waits on its own input when a title ends in `=-` (#1104).
