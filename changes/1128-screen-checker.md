The screen checker reads any absolute path of the machine (`/bin/sh`, `/Library/...`, a UNC path, `C:\` and `C:/`) unless it is glued to a word, a link, `~`, a glob, a placeholder, `GET /api/...`, `2>/dev/null` or a shebang. A next step or a fix counts only a backticked command: text starting with a known command word and another word, or with `./`. A `- ` list item ends a run of prose, and a waiver's reason must name every rule the screen breaks. A `Next:` line that is a sentence ends with a full stop and starts with a small letter, and the reporter's GitHub Actions branch has a test (#1128).
