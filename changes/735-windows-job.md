On Windows, a done-when check stops programs it left running after `cmd.exe` exits (#735). On Linux, a check that ends also stops a program in a new process group in its session. A program that has already started its own session, such as `setsid`, is still left running. If Windows has no job host, the check runs without a job and says why on stderr. The same holds when the host cannot start, compile its script, or make the job. So does a host that stops before it starts the check. A host that stops after it started the check is not detected. A program it leaves running can then keep running.
