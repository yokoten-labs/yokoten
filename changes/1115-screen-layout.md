Changed

Screens are easier to read (#1115). Every table on a help page starts its text in one column. When an item wraps onto a second line, a blank line now goes between items: in a guard refusal (Why, Instead, More), in a session note, in the road at a session start, in init's notes and in every table (help pages included). A problem ends with its fix on a line of its own, such as `Fix: \`yokoten init\`` when `yokoten update` runs outside a set-up project; `yokoten doctor` says each fix once, and problems that share a fix share one row. A usage error shows the word you typed, what the command does, then the help command. Outside a git repo, a command says `this folder is not in a git repo` and gives the next step on its own line; when git is missing, it says to install git or add it to PATH. Five long examples in the help got shorter forms.
